# Streamline

A Netflix-inspired streaming discovery interface built with vanilla HTML, CSS, and JavaScript. Browse a fictional catalog, search and filter titles, open details, and save favorites to My List.

**Live demo:** https://streamline-streaming-demo.netlify.app/

## Features

- Cinematic featured title and responsive catalog rows
- Search and genre filters
- Title detail modal
- My List saved in browser local storage
- Responsive layout for desktop and mobile

## Run locally

This is a buildless static site. Open `index.html` directly, or serve the repository root with a local web server, for example:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Stack

HTML, CSS, and JavaScript. The catalog is fictional and playback buttons are interface demos; this project does not stream licensed video.
